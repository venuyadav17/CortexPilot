# CortexPilot

## 🚀 Overview

CortexPilot is an AI-powered Code Review Copilot designed to help developers analyze code, identify bugs, suggest improvements, and explain code using Large Language Models (LLMs).

The project is being built step by step with a production-oriented approach using FastAPI as the backend.

---

## 🎯 Goal

Build a reliable AI assistant that can:

- Review code snippets
- Detect potential bugs
- Suggest code improvements
- Explain code logic
- Use Retrieval-Augmented Generation (RAG) for context-aware answers
- Apply safety guardrails
- Return structured API responses
